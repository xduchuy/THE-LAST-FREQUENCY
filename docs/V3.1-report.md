## Limits and remote CI

- Local runs use Node 24 and Chromium 154 with SwiftShader for actual 3D tests. CI is configured for Node 22 with Playwright-managed Chromium; a local pass is not a claim that GitHub CI ran green.
- Reading the GitHub Actions API with existing authentication returned `Forbidden`. Repository Git transport is checked independently. Remote CI status is UNVERIFIED until a workflow run can be inspected on GitHub.
- Tests emulate touchscreen and viewport behavior in Chromium. Physical iOS/Android devices and WebKit/Safari have not been tested.
- Only the verified V2.2 v1-key schema and known V3/3.1 schemas are supported. Storage is origin-specific; another domain or file:// storage cannot be silently imported. Quota/security failures keep gameplay usable and report persistence limits; unsupported current versions are protected from overwrite.
- No deployment is configured or performed. `npm run build` creates a static `dist/` ready for separate hosting.
